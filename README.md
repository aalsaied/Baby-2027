# الصورة السرية – إصدار الأدمن الموحد (v2)

## الإعدادات المعتمدة
- رابط موقع واحد لجميع المستخدمين.
- الأدمن ينشئ غرفة ويحدد اسمي الفريقين ورموز دخولهما ورمز الأدمن السري.
- الفريقان يفتحان نفس الرابط ويختاران وضع «فريق» ثم يدخلان رمز الغرفة ورمز الفريق.
- التلفزيون يفتح نفس الرابط ويختار «شاشة» ثم يدخل رمز الغرفة.
- الأدمن يبدأ المنافسة بعد اتصال الفريقين.
- أول فريق يركب 48 قطعة يفوز، وتظهر شاشة الكشف باللون الأزرق وعبارة «إنه ولد!» على الأجهزة المتصلة.
- الفيديو غير مضاف حالياً ويمكن إضافته لاحقاً.

## التشغيل
يتطلب Node.js 18 أو أحدث:
1. فك ضغط الملف.
2. شغّل `npm install`
3. شغّل `npm start`
4. افتح `http://localhost:3000`

## النشر
انشر المشروع على خدمة تدعم Node.js وWebSocket (مثل Render أو Railway):
- Build: `npm install`
- Start: `npm start`

## خطوات الحفلة
1. الأدمن يفتح الرابط ويختار «أدمن».
2. يكتب أسماء الفريقين، ويحدد رمزاً لكل فريق، ويحدد رمز الأدمن.
3. ينشئ الغرفة ويشارك رابط الموقع ورمز الغرفة مع الجميع، ويعطي كل فريق رمزه الخاص.
4. كل فريق يفتح الرابط نفسه ويختار «فريق» ويُدخل رمز الغرفة ورمزه.
5. شاشة التلفزيون تفتح الرابط نفسه وتختار «شاشة» وتُدخل رمز الغرفة.
6. الأدمن يضغط «ابدأ المنافسة» بعد دخول الفريقين.

## حدود النسخة الأولية
- لم تُنشر على الإنترنت بعد؛ الملف مشروع جاهز للنشر وليس رابطاً عاماً مستضافاً.
- بيانات الغرف في ذاكرة الخادم وتُمسح عند إعادة تشغيله.
- يلزم اختبارها على عدة أجهزة قبل الحفلة.
- واجهة الفوز الزرقاء ثابتة حالياً، والعد التنازلي موجود. مؤثر صوت دقات القلب ومقطع الفيديو يحتاجان إضافة أصول صوت/فيديو لاحقاً.
- النسخة الأولية تعتمد تحديثات تقدم من المتصفح؛ لا تستخدمها كمسابقة بجوائز عالية القيمة دون إضافة تحقق خادمي أدق من صحة كل قطعة.
